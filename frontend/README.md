# AI Agent Frontend

Frontend moderno em React + TypeScript + Tailwind CSS para a plataforma de atendimento com IA.

## 🚀 Início Rápido

1. Instalar dependências:
```bash
npm install
```

2. Configurar variáveis de ambiente:
```bash
cp .env.example .env
# Editar .env com suas configurações
```

3. Iniciar servidor de desenvolvimento:
```bash
npm run dev
```

4. Acessar: http://localhost:3000

## 📦 Estrutura

- `/src/pages` - Páginas principais (Chat, Treinamento, Configurações, Dashboard)
- `/src/components` - Componentes reutilizáveis
- `/src/services` - Integração com API

## 🎨 Tecnologias

- React 18
- TypeScript
- Tailwind CSS
- React Router
- Axios
- Lucide React (ícones)

## 🔧 Build

```bash
npm run build
```

## 📝 Páginas

- **Chat**: Interface de conversa com a IA
- **Treinamento**: Gerenciar base de conhecimento
- **Configurações**: Ajustar comportamento do agente (threshold, temperatura, etc.)
- **Dashboard**: Métricas e estatísticas
